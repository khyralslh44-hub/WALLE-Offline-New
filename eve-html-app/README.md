# إيف — نسخة أندرويد من ملف HTML المرفق

هذا مشروع Android مستقل يفتح واجهة HTML محلياً داخل WebView، ويستخدم واجهة Android للنطق العربي وصلاحيات الكاميرا والميكروفون.

## البناء
يُبنى APK تجريبي عبر GitHub Actions في مهمة **EVE HTML Android Build**. بعد نجاح المهمة، نزّل الأثر **EVE-HTML-APK** وخذ الملف `app-debug.apk`.

## ملاحظات مهمة عن القدرات
- يتم حفظ الذاكرة في تخزين WebView المحلي على الجهاز.
- الكاميرا والميكروفون يحتاجان منح الصلاحيات من أندرويد.
- الصوت العربي يستخدم خدمة تحويل النص إلى كلام المثبتة في الهاتف؛ وجود صوت عربي دون اتصال يعتمد على حزمة الصوت بالجهاز.
- ملف HTML يشير إلى خادمي لغة ورؤية اختياريين على `127.0.0.1:8080` و`:8081`، وهما غير مضمّنين في هذا المشروع. عند غيابهما، تعمل القواعد المحلية والواجهة فقط.
- جزء الرؤية في HTML ليس نموذجاً عاماً لفهم كل الأشياء والأفعال، ولا يثبت هوية الأشخاص.
- تم تقسيم التدريب الأولي للشبكة إلى دفعات صغيرة كي تظهر الواجهة أثناء التدريب بدلاً من تجميد الشاشة.
