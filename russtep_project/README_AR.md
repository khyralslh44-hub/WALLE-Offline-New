# روسي خطوة — إصدار أندرويد محلي

تطبيق تعلّم روسي بالعربية موجّه لجلسات قصيرة ومراجعة متباعدة وحفظ التقدّم على الجهاز.
ملف HTML يحتوي على المقاطع الصوتية المضمّنة يُنسخ إلى assets/index.html أثناء البناء.
لا يحتاج التطبيق إلى إذن الإنترنت، كما أن WebView يمنع تحميل الشبكة.
إنتاج APK: ./gradle assembleDebug أو تشغيل سير عمل GitHub Actions المرفق.
